Make room for what’s next.

Choose a tab, edit its text, or add an entry. Preview your changes, then download content.js and replace the existing file in your website folder or GitHub repository.

Drafts are saved only in this browser when storage is available; they are not published automatically. Export a backup to keep your work or move between devices.

How to publish an update
  1. Edit a tab and preview it.
  2. Download content.js. If the browser renames it content (1).js, rename it to content.js.
  3. Replace content.js in the website folder, then refresh index.html.
  4. For the public website, upload content.js to the GitHub repository and branch used by GitHub Pages.

This editor does not access GitHub. Anyone can open it, but changes affect only their browser until a repository owner publishes the file.
